**Ligature Substitution** is a GSUB rule that replaces two or more glyphs or glyph classes with a single glyph.

```fea
sub f i by fi;
```

Rules are written inside a feature block. Used in the `liga` feature, for example:

```fea
feature liga {
    sub f i by fi;
} liga;
```

## Syntax

```fea
sub <glyph sequence> by <glyph>;
```

- `<glyph sequence>` — two or more glyphs or glyph classes, written in the order they occur.
- `<glyph>` — the single glyph that replaces the whole sequence.

### Shorthand

`sub` is the short form of `substitute`. These two rules are the same:

```fea
substitute f i by fi;
```

```fea
sub f i by fi;
```

### Rule order

Within a block, longer sequences are matched first.

The first matching rule is the one applied (first match wins), so rules that replace more glyphs must be stored first. The specification requires the compiler to do this sorting, so the order you write the rules in does not matter.

### How the lookup type is determined

The syntax is similar to [Lookup Type 2](/fea/gsub/lookup-2/), but there is no need to state the Lookup Type. The compiler determines it from the shape of the rule.

```fea
# two glyphs → one glyph = Ligature Substitution (Lookup Type 4)
sub f i by fi;
```

```fea
# one glyph → two glyphs = Multiple Substitution (Lookup Type 2)
sub fi by f i;
```

## Features that use this lookup type

{/* TODO: /opentype/gsub/{tag}/ 作成時に各フィーチャーの外部リンクを内部リンクへ差し替え */}

The OpenType specification recommends implementing the following features with this lookup type.

- [`liga`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ko#tag-liga) — Standard Ligatures. Common ligatures such as *fi* and *ffl*.
- [`dlig`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ae#tag-dlig) — Discretionary Ligatures. Decorative ligatures applied only when the user asks for them explicitly.
- [`hlig`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_fj#tag-hlig) — Historical Ligatures. Ligatures from historical orthography, such as long s combinations.
- [`rlig`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_pt#tag-rlig) — Required Ligatures. Ligatures the script requires, such as Arabic *lam-alef*.
- [`ccmp`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ae#tag-ccmp) — Glyph Composition/Decomposition. Merges a character sequence into a single glyph before other features run.
- [`frac`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_fj#tag-frac) — Fractions. One recommended implementation maps digit–slash–digit sequences to precomposed fraction glyphs.

[`clig`](https://learn.microsoft.com/en-us/typography/opentype/spec/features_ae#tag-clig) (Contextual Ligatures) also forms ligatures, but it works only in specific contexts, so it is written with contextual rules.
