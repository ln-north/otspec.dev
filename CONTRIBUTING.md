# Contributing

**This project is not accepting contributions yet.**

Pull requests and issues from outside collaborators are currently disabled. This is deliberate, and it is not about the quality of your work.

## Why

otspec.dev is in early construction. Almost nothing is written: at the time of writing there is one real reference page, and the rest of the site is scaffolding. The structure of the site, the shape of each page type, and the voice of the prose are all still being worked out, and they change from week to week.

More importantly, this is a project I am using to learn the OpenType specification properly. Writing each page is the point, not a means to an end. Accepting text written by someone else — and in particular text generated by a language model — would remove the reason the project exists.

Every page here is written by a human who read the primary sources for that page, and checked the claims against a real font or a real compiler. That standard is easier to hold to while the project is small.

## Later

Contributions will open once the structure is settled and there is enough of the site for a contribution to have somewhere to fit. When that happens, this file will describe how to write a page, what the primary sources are, and how claims are expected to be verified.

If you want to follow along, watch the repository.

## Reuse

The code and content are MIT licensed. You are free to fork, adapt, and reuse without asking.

# コントリビューションについて

**このプロジェクトはまだコントリビューションを受け付けていません。**

コラボレーター以外による Pull Request と Issue の作成を、現在ブロックしています。意図的なもので、いただく内容の質とは関係ありません。

## 理由

otspec.dev は構築の初期段階にあります。中身のあるリファレンスページは現時点で 1 枚だけで、残りは骨格だけの状態です。サイトの構造、各ページ型の形、文章のトーンはいずれもまだ固まっておらず、短い周期で変わり続けています。

そしてより本質的な理由として、これは私が OpenType 仕様をきちんと学ぶためのプロジェクトです。1 ページずつ書くこと自体が目的であって、手段ではありません。他者が書いた文章を——とりわけ言語モデルが生成した文章を——受け入れることは、このプロジェクトが存在する理由を失わせます。

ここにあるページはすべて、そのページの一次資料を読んだ人間が書き、主張を実際のフォントやコンパイラで確かめた上で公開しています。この基準は、プロジェクトが小さいうちのほうが保ちやすいものです。

## 今後

構造が固まり、貢献の受け皿となる分量が揃った時点で受け付けを開始します。そのときはこのファイルに、ページの書き方、一次資料として何を参照するか、主張をどう検証するかを記載します。

進捗を追いたい場合は、リポジトリを Watch してください。

## 再利用について

コードとコンテンツは MIT ライセンスです。fork・改変・再利用は自由に行ってください。許可を求める必要はありません。
