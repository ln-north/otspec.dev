# Contributing

Pull requests are not being accepted at the moment.

I want to learn the OpenType specification by writing this site myself. If a lot of AI-generated pull requests arrive, I will not be able to read them fast enough to keep up — and even for generated text, I would rather keep editing everything myself for now, so that the tone stays consistent across the site.

Once there is enough content and the structure has settled, I plan to accept pull requests and enhancement proposals.

---

# コントリビューションについて

いまは Pull Request を受け付けていません。

OpenType 仕様を自分で学びながら書き進めたいためです。生成 AI で大量に送られても理解が追いつかないですし、生成されたものであっても、トーンを揃えるためにひとまず独裁的に推敲したいと思っています。

ある程度コンテンツが揃って整ったら、Pull Request や改善提案を受け付けたいと思っています。
